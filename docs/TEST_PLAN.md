# 人工验收计划

## 准备

- [ ] ST 版本在 1.14.x–1.18.x
- [ ] 通过仓库链接安装，无 Termux 操作
- [ ] 工具窗口显示「免服务端模式已就绪」
- [ ] 使用支持 CORS 的测试中转站

## 安装与配置

- [ ] 未启用 Server Plugins 也能打开扩展
- [ ] Base URL 为 `/v1` 时预览不出现 `/v1/v1`
- [ ] 模型拉取成功并进入下拉框；失败后保留上一次缓存
- [ ] 连接测试不会触发生图费用
- [ ] Key 留空保留，清除按钮才删除
- [ ] 聊天 JSON、图片 metadata 和控制台不含完整 Key
- [ ] CORS 失败时显示明确中文提示
- [ ] HTTP 默认拒绝，开启时有安全警告

## 标签与恢复

- [ ] AI 消息单标签完成后出现卡片，流式中不调用
- [ ] 一条消息两个标签出现两个独立卡片
- [ ] 用户消息、system、reasoning 标签不处理
- [ ] 未闭合和嵌套标签不处理
- [ ] 刷新、切换聊天、关闭重开后恢复且不增加上游调用
- [ ] 编辑消息：未变标签保留历史，变更标签获得新卡片

## 聊天瘦身与聊天文件体积（1.7.0）

- [ ] 旧版聊天（楼层 `extra.stImageAtelier.tags[i]` 里有 `attempts`）打开后卡片照常显示，控制台没有报错
- [ ] 设置页「界面与画廊」最下面的「瘦身当前聊天」先弹确认，确认里写明楼数、大小、要删几张图
- [ ] 瘦身后状态行显示「瘦身前 → 瘦身后」，控制台有「瘦身前 / 瘦身后：生图标签数据共 N 字节」两行
- [ ] 瘦身后已有图片仍能显示、翻看，「重新生成」和删除照常；再点一次瘦身显示「已经是精简形」
- [ ] 819 楼的聊天瘦身后 `extra.stImageAtelier.tags` 总量在 2 MB 以内
- [ ] 新出一张图后用 `/api/chats` 或聊天 JSON 核对：这一楼的 tag 没有 `attempts`，只有 `resultRefs`
- [ ] 单楼 tags 超过 20 KB 时控制台出现 `[画笺] 第 N 楼的生图标签数据有 … 超过 20.0 KB` 警告

## 手动与自动生图

- [ ] 手动点击一次只发一个上游请求
- [ ] 快速双击仍只发一个请求
- [ ] 同标签重新生成新增历史结果
- [ ] URL 与 Base64 返回都保存到酒馆图片目录
- [ ] 开启自动后仅新完成 AI 消息触发
- [ ] 同消息四个标签时仅前三个自动
- [ ] 自动失败不重试
- [ ] 删除自动图片后不自动补图

## NovelAI

- [ ] GPT 与 NovelAI 切换后只使用当前引擎，原有 GPT 预设不被覆盖
- [ ] NovelAI Token 留空保留，只有清除按钮会删除
- [ ] 新建、重命名、切换和删除画师串预设均可用
- [ ] 实际请求提示词顺序为「画师串 → 正文 → 质量标签」
- [ ] V4/V4.5/V5 请求包含对应的结构化 prompt 参数
- [ ] 官方 ZIP 响应和第三方 JSON/Base64 响应都能保存
- [ ] 多图 ZIP 会逐张进入同一卡片历史与画廊
- [ ] 401、402、429 与浏览器/CORS 错误显示可理解的中文原因

## 画廊

- [ ] 从 1.6.1 升级后，旧画廊迁入 `st-image-atelier-gallery.json`，`extension_settings.stImageAtelier` 不再含画廊或墓碑
- [ ] 新增一条画廊记录前后 `settings.json` 文件大小与内容保持不变
- [ ] 结果按时间倒序显示
- [ ] 查看和下载原图可用
- [ ] 删除前确认
- [ ] 删除后底层文件消失且刷新不复活
- [ ] 最新图删除后卡片回退到次新图

## 视觉

- [ ] 浅色和深色主题均清晰
- [ ] 390×844 视口不横向溢出
- [ ] 主要触控区域至少 44×44 px
- [ ] Esc、遮罩、关闭按钮均能关闭窗口
- [ ] `prefers-reduced-motion` 下无持续动画

## 可选增强模式

- [ ] 显式安装 Server Plugin 后能切换模式
- [ ] 服务端未安装时选择增强模式会显示明确错误
- [ ] 切回免服务端模式后无需重启即可继续配置
